# 수습기자 교육운영 미니리더

수습기자 기본교육의 사전준비부터 결과보고까지 업무를 체크리스트로 표준화하는 서버 없는 정적 웹 MVP입니다. 현재는 기능 검증을 위한 샘플 업무 20건이 포함되어 있습니다.

## 실행 방법

`data/tasks.json`을 브라우저에서 불러오므로 로컬 웹 서버로 실행합니다.

```powershell
python -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000`을 엽니다. Python이 없다면 VS Code Live Server 등 정적 파일 서버를 사용할 수 있습니다.

## 프로젝트 구조

```text
index.html          화면 구조
css/styles.css      공공기관 내부 업무용 UI 스타일
data/tasks.json     업무 원본 데이터(향후 약 110개로 확장)
js/app.js           앱 초기화, 검색/필터/정렬 이벤트
js/dashboard.js     요약 카드와 단계별 진행률
js/tasks.js         업무 카드 렌더링과 업무 이벤트
js/storage.js       localStorage 상태 저장/조회
```

## 주요 기능

- 전체 업무, 완료, 진행, 미착수, 전체 진행률 및 단계별 진행률 표시
- 단계 탭, 필수/미완료/마감임박 필터, 업무명/설명/주의사항 검색
- 기준일, 담당역할, 완료기준, 주의사항, 필수 여부가 포함된 카드 UI
- 완료 체크, 완료일 자동 기록, 인수인계용 메모 저장
- 브라우저 `localStorage`에 업무 처리 상태만 저장하며 교육생 개인정보는 저장하지 않음

## 데이터 확장

실제 업무를 반영할 때는 `data/tasks.json`의 객체를 추가하거나 수정합니다. 기존 `id`를 유지하면 현재 브라우저에 저장된 처리 상태가 해당 업무에 계속 연결됩니다. 업무 데이터에 이름, 전화번호, 주민등록번호, 계좌번호 등 개인정보를 넣지 마세요.

## 검증

현재 별도 빌드/테스트 도구는 없습니다. 로컬 서버 실행 후 각 단계 필터, 검색, 필수/미완료/마감임박 필터, 완료 체크, 메모 입력, 브라우저 새로고침에 따른 상태 유지 여부를 확인합니다.
