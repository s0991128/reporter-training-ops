# 업무 데이터 작성 규격

## 목적

운영 업무 문장과 순서의 기준은 `업무목록.csv` 117건입니다. 각 CSV key의 일정·단계·위험·의존성 등 확장 정보는 `data/checklist-metadata.json`에 보관하고, 두 파일은 실행 시 1:1로 검증합니다. `data/tasks.json`은 JSON 스키마와 업무 마스터 편집을 검증하기 위한 샘플 20건으로 별도 유지합니다. 완료 상태와 메모는 업무 원본과 분리된 `localStorage`에 저장합니다.

## 필드 규칙

| 필드 | 필수 | 타입 | 설명 |
| --- | --- | --- | --- |
| `id` | 예 | 문자열 | 영구 식별자. 신규 업무는 `PRE-001`, `OPS-001`, `CLS-001`, `FIN-001`, `RPT-001` 형식을 사용합니다. |
| `phase` | 예 | 문자열 | `사전준비`, `교육운영`, `종료처리`, `정산`, `결과보고` 중 하나입니다. |
| `timing` | 예 | 객체 | `type`, `value`, `label`을 가집니다. 유형은 `D_DAY`, `TRAINING_DAY`, `END_DAY`, `AFTER_END`, `MANUAL`입니다. |
| `category` | 예 | 문자열 | 기획, 교육과정, 강사, 교육생, 시설, 숙박, 교통, 식사, 물품, 안내, 행정, 계약, 예산, 정산, 설문, 성과, 결과보고, 기타 중 하나입니다. |
| `title`, `description` | 예 | 문자열 | 업무명과 업무 설명입니다. |
| `required` | 예 | 불리언 | 필수 업무 여부입니다. |
| `assigneeRole` | 예 | 문자열 | 개인 이름이 아닌 담당 역할입니다. |
| `estimatedMinutes` | 예 | 정수 | 예상 소요 시간(분)입니다. |
| `completionCriteria` | 예 | 문자열 배열 | 완료를 판단할 기준을 항목별로 작성합니다. |
| `riskLevel` | 예 | 문자열 | `HIGH`, `MEDIUM`, `LOW` 중 하나입니다. |
| `dependencies` | 예 | 문자열 배열 | 선행 업무 ID 목록입니다. 존재하는 ID만 참조합니다. |
| `documents` | 예 | 객체 배열 | 관련자료 이름과 필수 여부입니다. |
| `handover` | 예 | 객체 | `caution`, `knowhow`, `previousIssue`를 기록합니다. 확인되지 않은 사례를 임의로 만들지 않습니다. |
| `budget` | 예 | 객체 | 예산 관련 여부와 예산 분류입니다. |
| `repeat`, `aiCheck` | 예 | 객체 | 향후 반복 일정과 누락점검 확장을 위한 자리입니다. |
| `tags` | 예 | 문자열 배열 | 검색과 분류를 위한 태그입니다. |
| `active` | 예 | 불리언 | 운영 중인 업무인지 표시합니다. |
| `sortOrder` | 예 | 숫자 | 같은 단계 안에서의 표시 순서입니다. |

## 일정 작성

사전준비의 상대 일정은 `{"type":"D_DAY","value":-7,"label":"D-7"}`처럼 기록합니다. 교육일차는 `TRAINING_DAY`와 양의 일차 값을 사용하고, 종료 당일은 `END_DAY`, 종료 후 일정은 `AFTER_END`를 사용합니다. 날짜를 특정할 수 없는 업무는 `MANUAL`을 사용합니다.

## 개인정보 금지

이름, 전화번호, 주민등록번호, 계좌번호, 주소, 개인 이메일, 숙박 개인정보를 업무 데이터에 넣지 않습니다. 개인정보 관련 업무는 `교육생 명단 확인`, `지급정보 처리 완료`처럼 처리 여부와 담당 역할만 정의합니다.

## 실제 업무 입력 절차

새 업무는 중복되지 않는 영구 ID를 먼저 정하고, 단계와 기준일을 선택한 뒤 완료기준을 관찰 가능한 문장으로 작성합니다. 선행 업무가 있을 때만 `dependencies`에 ID를 추가하며, 자기 자신이나 후속 업무를 참조하지 않습니다. 저장 전 `js/validator.js`의 필드·prefix·순환 검증과 개인정보 포함 여부를 확인합니다.
