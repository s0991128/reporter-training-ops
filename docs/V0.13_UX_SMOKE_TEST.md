# v0.14 UX 스모크 테스트

로컬 서버(`npm start`)에서 아래 항목을 순서대로 확인합니다. 테스트 중 입력한 메모는 개인정보가 아닌 예시 문구만 사용합니다.

1. 최초 진입 시 제목이 `수습기자 기본교육 운영`이고 `교육운영`이 열리는지 확인한다.
2. 상단 직접 메뉴가 교육운영, 교육일정, 예산·정산, 더보기의 네 개인지 확인한다.
3. KPI 카드에서 현재 진행 구간, 진행률, 완료, 진행중, 미완료, 해당없음이 읽기 쉽게 보이는지 확인한다.
4. 더보기에서 업무기준 관리, 인수인계, AI 누락점검, 데이터 관리가 열리는지 확인한다.
5. 교육운영에서 현재 진행 구간의 업무만 기본 표시되는지 확인한다.
6. 현재·이전·다음 구간 버튼과 `전체 구간 ▾` 선택에서 16개 구간을 선택할 수 있고 가로 스크롤이 생기지 않는지 확인한다.
7. 현재 구간 업무가 4건보다 적은 경우 다음 구간 미리보기로 첫 화면에 4개 행이 보이는지 확인한다.
8. `먼저 확인` 영역에 우선 업무가 표시되고 업무명 클릭으로 해당 행에 초점이 이동하는지 확인한다.
9. 검색어로 업무·구간·비고·메모가 필터링되는지 확인한다.
10. 현재구간, 미완료, 진행중, 전체업무 필터가 작동하는지 확인한다.
11. 필터 메뉴에서 완료·해당없음 필터가 작동하는지 확인한다.
12. 개인정보 주의와 CSV 검증 상태가 한 줄 보조정보로 표시되는지 확인한다.
13. 업무 행의 상태 선택, 3회 체크 표시, 메모 버튼과 상세 텍스트가 충분히 읽히는지 확인한다.
14. 일반 업무의 상태를 변경한 뒤 새로고침해도 상태가 유지되는지 확인한다.
15. 3회 체크 업무를 펼쳐 1/3, 2/3, 3/3에 따라 진행중·완료가 바뀌는지 확인한다.
16. 한 행을 열 때 다른 행의 상세가 닫히는지 확인한다.
17. 상세에서 메모를 저장하고, 전화번호·계좌번호처럼 개인정보로 보이는 값은 저장되지 않는지 확인한다.
18. 인수인계 화면에서 현재 구간, 메모, 최근 처리와 HTML 보고서 생성이 정상인지 확인한다.
19. AI 누락점검에서 자료를 추가하고 기본 비교가 실행되는지 확인한다.
20. AI 결과의 업무기준 관리 열기가 독립 페이지로 이동하고 원본을 자동 변경하지 않는지 확인한다.
21. 업무기준 관리에서 검색, 편집, 검증, CSV 가져오기/내보내기, JSON 내보내기가 정상인지 확인한다.
22. 예산·정산에서 계획예산 및 거래 입력과 정산 상태 변경이 정상인지 확인한다.
23. 교육일정과 더보기의 데이터 관리(백업/복원 미리보기)가 기존대로 작동하는지 확인한다.
